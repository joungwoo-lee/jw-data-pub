weekly-report-review

임원 주보를 매주 모아 사용자가 넣은 조직 역할 카드(없으면 요청, 지시 시 웹 조사)와 대조한 근거 리포트를 사람마다 쌓고, 사용자가 KPI/MBO 를 주면 척도대로 제안 점수를 낸다. 최종 판단은 사람. 마스터 세션은 산출물을 읽지 않고 순서도 정하지 않는다 — Workflow 도구 한 번 호출로 사람마다 독립 파이프라인이 돌고, 마스터는 반환 요약 전달·카드/KPI 요청·개입(사실 바꾸기)만. 첫 에이전트가 폴더 사실에서 다음 단계를 계산하므로 매주 다시 호출하면 이어진다.

1. 한눈에 — 사람 한 명의 흐름

보라 = 워크플로우 루프 · 빨강 = 사람 · 회색 = 실행자 1회. 루프(실행자→스크립트→감독자→memory→재시도)는 리포트를 쓰는 4(1차)·7(2차)에서만 돈다. 1·2·3·5 는 실행자 1회, 6 은 새 주차를 붙여 4 를 다시 도는 것.

2. 검사 세 겹 — 싼 것부터. 루프는 리포트 작성(4 · 7)에서만

겹무엇을 잡나비용 (2026-09-20 실측, 1명)
① 스크립트인용 글자 대조 · 원문 문장이 정규화본에서 누락 · 주보 문장이 리포트에서 누락 · 역할 항목 전부·있음/없음 · 근거 종류↔인용 출처 · 반복 주차 표기 · 카드/KPI 버전 · prev 1차·2차·평가자 열 보존 · 점수어·코드 라벨 · 3축 재계산 · KPI 달성률 재계산·행 ID0 토큰

3. 실행 — Workflow 도구 한 번

대본 단계누가무엇
계획에이전트 1 (모델은 전부 마스터 상속)폴더 사실(파일 유무 · report.md status · 카드/KPI 버전 · period 뒤 새 주차)만 보고 사람마다 다음 단계. 사용자 지시(args.note)는 여기서 반영
사람마다parallel + 세마포어(max_parallel)계획된 단계부터 끝까지 이어서. 카드·KPI 없으면 그 사람만 사용자 대기로 반환, 자리 반납
루프 (4·7)실행자 → 검사 에이전트 → 감독자 → 마크≤3회. 스크립트 FAIL 은 errors 를 다음 실행자에게, 감독자 fail 은 memory 줄을 대본 배열에 쌓아 다음 실행자·다른 사람에게. 2회째 같은 반려·같은 기준 3연속 → 그 기준 보류하고 계속(사람에게 안 묻음). 정규화 누락은 2단계 자동 재실행
기록에이전트 1 (사람마다)progress.md 줄 · memory/*.md 줄 append. 반환은 사람마다 한 줄 요약
개입은 순서를 말하지 않고 사실을 바꾼다: 새 주보 = email-raw 에 넣기 · 주보 수정 = 그 주차 email-weekly 삭제 + status: draft · 리포트 지시 = memory [사용자] 줄 + status: draft · 카드 교정 = 버전 +1 · KPI 변경 = kpi-card 버전 +1 · 평가자 점수 = score_status: draft. 오케스트레이션 파일 없음, 스크립트는 verify_quotes.py(검사) 하나.

5. 점수 로직 — 왜 이렇게 세나 · 한계

점수 축은 역할 커버·결정·리스크·진전 3개. KPI 는 점수를 매기지 않는다 — 항목마다 주보 인용 근거를 한 자리에 모으고 최종 목표 대비 달성률 한 숫자만. 시간 보정·온트랙 판정 없음, 판단은 평가자.
합리적인 면어떻게
적힌 것만주보에 인용된 숫자·결정·리스크만 근거. 없으면 "수치 없음"이지 0 아님
근거는 원문 전문KPI 항목마다 관련 주보 문장을 전문으로 모으고 verify_quotes 가 주보와 글자 대조 — 지어낸 근거 차단
달성률 한 가지 식높을수록 좋음 = 끝값÷목표, 낮을수록 좋음 = 목표÷끝값. 스크립트가 다시 센다
남의 결과는 비고다른 조직 책임·통제 불가 사건은 비고에 적고, 뺄지는 평가자가 정한다
제안일 뿐3축 제안 점수, 최종은 평가자. 차이 이유가 사람을 바꿔 2건 이상이면 척도 수정
한계안 되는 것
주보 의존숫자를 안 적으면 "수치 없음", 유리한 숫자만 적어도 반영. 진짜인지는 스크립트가 모름
시점 보정 없음12월 목표를 9월에 보면 50% — 기한 칸을 보고 평가자가 판단
기준선 미사용출발점이 달라도 같은 달성률. 기준선은 목표 칸에 적혀 있을 뿐
목표 0 은 % 불가"편차 0주" 같은 지표는 값만 그대로
3축은 개수근거 종류 개수 세기 — 일의 난이도는 못 봄
평가자 점수 0건사람 점수와 견줘 다듬어야 척도가 자리 잡음
